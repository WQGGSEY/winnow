HuggingFace datasets

HuggingFace datasets are not registered here. They are referenced directly from an experiment's dataset_spec using source: "hf://<repo_id>". The HuggingFaceMaterializer downloads them on demand using the HF cache at ~/.cache/huggingface/. Install datasets and huggingface_hub (and set HF_TOKEN for gated repos) before running.
