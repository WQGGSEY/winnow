# Research progress before the next E2E

The live research remains stopped. This document records reasoning and offline
checks, not evidence that the harness can produce a publishable paper.

## Decision

Keep the final scientific bar and the sealed confirmation boundary. Improve the
development loop before paying for another research run. Do not provide a learner
or a Pacman-specific explanation to the research agent.

Use the existing planning call to interpret the previous result and choose the
next work. Do not introduce another paid reviewer at every transition. Persist
the interpretation, its evidence, unresolved alternatives, and relation to the
claim. The interpretation is a fallible development judgment, never scientific
qualification. Measurement differences alone are not knowledge gains.

## Scope and acceptance

Offline evidence must exercise real transitions with controlled inputs and no
model calls. Stubbed model responses can demonstrate evidence binding, invalid
transition rejection, replay, and cancellation. They cannot demonstrate good
hypotheses, sound scientific interpretation, or publication quality.

General theoretical research remains a separate architectural gap: the current
GoalContract requires a real holdout. Do not silently replace that contract with
a proof-only terminal or claim COLT support from the presence of a Lean checker.
The research goal, development protocol and confirmation contract must be
separated deliberately before that capability can be claimed.

Do not restart E2E while unresolved implementation gaps are described as fixed.

## Implemented boundaries

- Planning policy 18 interprets the completed previous work in the existing
  planning response. The host checks its work/evidence binding, coverage of the
  original predictions, and the distinction between operational failure,
  inconclusive evidence and an informative development judgment. Rejected
  responses become correction input; they do not silently repeat without feedback.
- Report ingestion rejects nonfinite numbers, including JSON exponent overflow.
- Empirical work declares eligible-observation count metrics. Missing, nonfinite
  or nonpositive support prevents an informative interpretation. This check does
  not establish adequate power, estimator correctness, or truthful measurements.
- The planner now receives critiqued hypothesis candidates and can link a work
  to them. Claim IDs and result interpretations survive in the working brief.
  Source-analysis references retain their evidence dependencies.
- Default planning input includes eight recent analysis excerpts and four
  implementation records, with a full evidence archive and brief on disk for
  targeted reading. Each planning invocation preserves its request, response and
  provider-reported usage. No additional interpretation model call is introduced.
- Work-scoped source acquisition reuses the existing HTTP policy, redirect,
  robots, cache and receipt implementation. The HTTP layer accepts only the
  identity and source plans it needs, rather than requiring a fabricated direction.
  PDF bytes survive extraction failure. A bibliography reference can acquire
  primary text after confirmation without changing experimental state.
- Manuscript evidence includes acquired primary sources and the working brief.
  Reviewers may inspect the supplied, hash-checked primary text; replay rejects
  a changed source. The literature reviewer additionally has native web search
  enabled, with instructions for three focused searches. Its tool events are
  preserved. Discovered omissions are unverified leads requiring acquisition and
  citation, not new scientific evidence. Search quality and actual query count
  are not proven by offline permission checks.
- Development implementation review uses a separate response contract. Every
  blocking change must cite a resolvable requirement, an exact quote and an
  applicable scope. Final-confirmation requirements and deferred questions
  cannot be installed as development blockers. A malformed or out-of-scope
  review is corrected on the same execution request; it does not request a
  code change or create a scientific observation. The original final bar and
  explicit applicable development protocol remain binding.
- Manuscript revision can retrieve missing primary literature without reopening
  confirmation. Changed manuscript or evidence ledger creates a new review
  snapshot under the existing submission lifecycle. Agent guidance no longer
  suggests repairing an implementation against observed holdout outcomes.
- Session cancellation captures detached descendants, retains identities through
  reparenting, and uses a session token to find surviving owned subprocesses.
  Supervisor shutdown and normal session cleanup both invoke it.

## Token-cost thought experiment

The last saved Pacman planning request contained 592,199 UTF-8 bytes. Its 37
analysis records occupied 125,797 bytes and 43 implementation records occupied
84,145 bytes. Applying the new default-view limits to that same record gives
27,374 and 8,023 bytes respectively, a reduction of 174,545 bytes in those two
fields. This is a static byte comparison, not a measured token or billing saving.
New interpretation, hypothesis and archive-reference fields also cost tokens.
Actual savings and retrieval quality remain unmeasured until a controlled live
run is warranted.

## Remaining design risks

The model still judges whether an experiment distinguishes meaningful causal
alternatives. Neither nonempty sample counts nor schema-conforming interpretation
proves that judgment correct. The host must not turn a supported *prediction*
into a validated *causal explanation*.

The working brief supplies evidence links and contribution questions. It is not
a demonstrated publication-quality argument. The host now separates development
review from final-confirmation prerequisites, but interpreting the applicability
of an existing prose protocol clause still requires judgment. Exact quotation
prevents an invented clause, not a mistaken interpretation of a real clause.
The final literature reviewer can search independently and inspect acquired
sources, but exhaustive coverage and accurate novelty judgment remain unproven.
These limitations must not be presented as fixed by offline checks.
